## MODIFIED Requirements

### Requirement: Search input validation
Поле пошуку SHALL не виконувати пошук за порожнім значенням, значенням із самих пробілів або коротшим за два символи (після обрізання пробілів і стискання повторних пробілів): запит на сервер у цих випадках не надсилається, поле позначається як некоректне. Для порожнього значення поле лише підсвічується червоним контуром, **без тексту підказки**; для закороткого значення під полем показується підказка про мінімальну довжину. Довший за 100 символів запит MUST обрізатися до 100 символів. Сервер MUST також відхиляти такі запити відповіддю 422.

#### Scenario: Empty submit
- **WHEN** відвідувач натискає Enter або кнопку пошуку з порожнім полем
- **THEN** контур поля підсвічується червоним, текстової підказки немає, запит не надсилається

#### Scenario: Too short
- **WHEN** відвідувач вводить один символ і натискає Enter
- **THEN** показується підказка про мінімальну довжину, запит не надсилається

#### Scenario: Server-side validation
- **WHEN** на ендпоінт пошуку надходить порожній або закороткий параметр запиту
- **THEN** відповідь 422 без звернення до пошукового рушія

#### Scenario: Long query
- **WHEN** запит довший за 100 символів
- **THEN** він обрізається до 100 символів
